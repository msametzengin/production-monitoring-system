# Üretim Analiz ve Takip Sistemi

Eti Maden Kütahya Emet işletmesindeki staj kapsamında geliştirilen üretim izleme ve analiz uygulaması.

## Amaç

Üretim miktarlarını, hedefleri, çalışma ve duruş sürelerini tesis ve ürün bazında takip ederek anlaşılır raporlar ve performans göstergeleri sunmak.

## Teknolojiler

- Next.js
- TypeScript
- Tailwind CSS
- MySQL
- Prisma ORM

## Planlanan Özellikler

- Tesis ve ürün yönetimi
- Vardiya bazlı üretim kayıtları
- Hedef–gerçekleşen karşılaştırması
- Çalışma ve duruş süresi analizi
- Dashboard ve grafikler
- Filtreleme ve raporlama
- Excel içe/dışa aktarma

## Proje Durumu

Hala geliştirme sürecinde.
